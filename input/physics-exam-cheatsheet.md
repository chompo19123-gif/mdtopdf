# สรุปก่อนสอบฟิสิกส์ (ของไหล + ความร้อน + ไฟฟ้ากระแสตรง)

ข้อสอบ 40 ข้อ ทฤษฎี ~ครึ่ง คำนวณ ~ครึ่ง
เป้าหมาย: 31+ ข้อ (ถ้าเกณฑ์ B = 70) คุณมี 39 คะแนนอยู่แล้ว

## 0. กฎเหล็ก 6 ข้อก่อนแทนค่าทุกข้อ (คุณพลาดตรงนี้บ่อยสุด)

| # | กฎ | ตัวอย่างที่เคยพลาด |
|---|----|--------------------|
| 1 | ขีดเส้นใต้ว่าโจทย์ **ถามอะไร** ก่อนคิด | ถามแรงตึงเชือก แต่ตอบน้ำหนักหรือแรงลอยตัว |
| 2 | ให้ **d หรือ r** แล้วถามเรื่องพื้นที่/ความเร็ว/R → **ยกกำลังสอง** (A = πr², A ∝ d²) | ปาสคาล, ความต่อเนื่อง, R ของลวด |
| 3 | ให้ **A มาตรงๆ** → ใช้ตรงๆ ห้ามยกกำลังสองซ้ำ | ปาสคาลที่ให้ 5 cm², 40 cm² |
| 4 | **°C → K (+273)** ทุกข้อที่เป็นแก๊ส และแผ่รังสี | ชาร์ล, เกย์-ลูสแซก, T⁴ |
| 5 | แปลงหน่วย: mA→A, kΩ→Ω, นาที→วินาที, cm→m (เมื่อมี g, ρ) | I = q/t, V = IR |
| 6 | เช็กทิศคำตอบว่าสมเหตุสมผล | ลูกสูบเล็กแรง **น้อยกว่า**ลูกใหญ่, ท่อแคบน้ำ **เร็วกว่า**, ลวดหนา R **น้อยลง**, น้ำผสมต้องอยู่ **ระหว่าง** สองอุณหภูมิ |

**ความดันสัมบูรณ์ vs เกจ**
- สัมบูรณ์ = P₀ + ρgh (ต้องบวก P₀ 1.013×10⁵ Pa)
- เกจ = ρgh (ไม่ต้องบวก)
- โจทย์ถามคำไหน ตอบคำนั้น

## 1. ของไหล

### 1.1 สถิตศาสตร์

| เรื่อง | สูตร / ใจความ |
|---|---|
| ความหนาแน่น | ρ = m/V |
| ความดัน | P = F/A (Pa = N/m²) |
| ความดันในของเหลว | P = ρgh |
| ความดันสัมบูรณ์ | P = P₀ + ρgh |
| ผลต่างความดัน | P₂ − P₁ = ρg(h₂ − h₁) |
| หลายชั้นของเหลว | P_bot = P₀ + ρ₁gh₁ + ρ₂gh₂ (ใช้ความสูงของแต่ละชั้น) |
| บารอมิเตอร์ | P₀ = ρ_Hg·g·h (บนหลอด P = 0 สุญญากาศ) |
| มานอมิเตอร์ | P = P₀ + ρgh, เกจ = ρgh |
| ปาสคาล | F₁/A₁ = F₂/A₂ และ A₁Δx₁ = A₂Δx₂ |
| แรงลอยตัว | F_B = ρ_ของเหลว · V_จม · g |
| วัตถุลอย | V_จม/V_วัตถุ = ρ_วัตถุ/ρ_ของเหลว |

หน่วยที่ต้องจำ: 1 atm = 1.013×10⁵ Pa, ρ น้ำ = 1000, ρ ปรอท = 13.6×10³ kg/m³

**ทฤษฎีที่ออกบ่อย**
- ความดันขึ้นกับ **ความลึก** ไม่ขึ้นกับรูปร่าง/ขนาดภาชนะ
- จุดลึกเท่ากันในของเหลวเดียวกัน ความดันเท่ากัน
- ปาสคาล: ความดันที่เพิ่ม ส่งไปทั่วของเหลวระบบปิดเท่ากัน
- ไฮดรอลิก: ได้แรงขยาย แต่ **เสียระยะ** (ลูกเล็กเคลื่อนไกลกว่า) ไม่ได้พลังงานฟรี
- อาร์คีมีดีส: แรงลอยตัว = น้ำหนักของเหลวที่ถูกแทนที่
- ρวัตถุ < ρของเหลว → ลอย / > → จม / = → ลอยนิ่ง
- วัตถุลอยนิ่ง: F_B = น้ำหนัก

### 1.2 พลศาสตร์

| เรื่อง | สูตร / ใจความ |
|---|---|
| ความต่อเนื่อง | A₁v₁ = A₂v₂ (วงกลม: v₂ = v₁·(d₁/d₂)²) |
| อัตราการไหล | Q = Av = V/t (m³/s) |
| แบร์นูลลี | P₁ + ½ρv₁² + ρgy₁ = P₂ + ½ρv₂² + ρgy₂ |
| ท่อแนวราบ (y เท่ากัน) | P₁ − P₂ = ½ρ(v₂² − v₁²) |
| รูข้างถังใหญ่ | v = √(2gh) (v₁ ≈ 0, P₁ = P₂ = P₀) |

**ของไหลอุดมคติ 4 ข้อ:** ไม่หนืด, ไหลคงตัว, ความหนาแน่นคงที่, ไม่หมุนวน
**ราบเรียบ (laminar):** ไหลเป็นเส้น ไม่ตัดกัน / **ปั่นป่วน (turbulent):** หมุนวน
**ท่อแคบลง:** เร็วขึ้น (ต่อเนื่อง) ความดันลด (แบร์นูลลี)

## 2. ความร้อน

| เรื่อง | สูตร / ใจความ |
|---|---|
| สเกล | T_K = T_C + 273, T_F = 1.8T_C + 32 |
| ร้อนขึ้น | Q = mcΔT (ΔT = สุดท้าย − เริ่มต้น, c น้ำ = 4200) |
| เปลี่ยนสถานะ | Q = mL (อุณหภูมิ **คงที่**) |
| L น้ำแข็ง | 3.33×10⁵ J/kg / ไอน้ำ 2.26×10⁶ J/kg |
| กำลัง | P = Q/t (เวลาเป็นวินาที) |
| นำ (แผ่นเรียบ) | P = kAΔT/L |
| นำ ทรงกลมกลวง | P = 4πk(T₁−T₂)·r₁r₂/(r₂−r₁) |
| นำ ทรงกระบอกกลวง | P = 2πkL(T₁−T₂)/ln(r₂/r₁) |
| พา | P = hA(T_h − T_c) |
| แผ่รังสี | P = eσAT⁴ (σ = 5.67×10⁻⁸, T ในเคลวิน) |
| แผ่รังสีสุทธิ | P_net = eσA(T_h⁴ − T_c⁴) |
| แก๊สอุดมคติ | PV = nRT (R = 8.314), PV = Nk_BT (k_B = 1.38×10⁻²³) |
| จำนวนโมล | n = m/M (M เป็น kg/mol), n = N/N_A (6.02×10²³) |
| สูตรรวมแก๊ส | P_iV_i/T_i = P_fV_f/T_f |

**กฎแก๊ส (ขีดตัวที่คงที่ออกจากสูตรรวม)**
- บอยล์: T คงที่ → P_iV_i = P_fV_f
- ชาร์ล: P คงที่ → V/T คงที่
- เกย์-ลูสแซก: V คงที่ → P/T คงที่
- อาโวกาโดร: P, T คงที่ → V/n คงที่
- ดาลตัน: P_total = P₁ + P₂ + ...

**ทฤษฎีที่ออกบ่อย**
- พลังงานความร้อน = พลังงานจลน์ **รวม** / อุณหภูมิ = พลังงานจลน์ **เฉลี่ย**
- นำ: ของแข็ง ต้องสัมผัส / พา: ของเหลว-แก๊ส อนุภาคพาไป / แผ่รังสี: ไม่ต้องมีตัวกลาง
- โลหะ k สูง (ตัวนำ) / ไม้ ยาง โฟม k ต่ำ (ฉนวน) จับโลหะรู้สึกเย็นเพราะดึงความร้อนจากมือเร็วกว่า
- เปลี่ยนสถานะ: อุณหภูมิไม่เปลี่ยน ความร้อนใช้แกะพันธะ
- ร้อนขึ้น: แผ่รังสีมากขึ้น และความยาวคลื่นที่แรงสุดสั้นลง
- แก๊สอุดมคติ: แก๊สความดันต่ำ ใช้สมการเดียวอธิบายได้

## 3. ไฟฟ้ากระแสตรง (กระแสสลับไม่ออก ข้ามได้)

| เรื่อง | สูตร / ใจความ |
|---|---|
| กระแส | I = Δq/Δt (A = C/s) |
| ความหนาแน่นกระแส | J = I/A |
| โอห์ม | V = IR |
| ความต้านทานลวด | R = ρL/A |
| ปรับตามอุณหภูมิ | R = R₀[1 + α(T − T₀)], ρ = ρ₀[1 + α(T − T₀)] |
| กำลัง | P = IV = I²R = V²/R |
| พลังงาน | E = Pt (J ใช้วินาที) หรือ kWh (kW × ชั่วโมง) |
| ประจุอิเล็กตรอน | e = 1.6×10⁻¹⁹ C |

**ทฤษฎีที่ออกบ่อย**
- ทิศกระแส (ข้อตกลง): จากขั้วบวกไปลบ / อิเล็กตรอนเคลื่อนทิศตรงข้าม และช้ามาก (~10⁻⁴ m/s)
- ไฟติดทันทีเพราะสนามไฟฟ้าแผ่ไปทั้งสายเกือบพร้อมกัน
- แบตเตอรี่: ปฏิกิริยาเคมีย้ายอิเล็กตรอนจากขั้วบวกไปลบ สร้าง EMF
- R เกิดจากอิเล็กตรอนชนอะตอมในลวด
- R ขึ้นกับ: ยาวขึ้น → R เพิ่ม / หนาขึ้น → R ลด / โลหะร้อนขึ้น → R เพิ่ม
- โอห์มมิก: R คงที่ กราฟ I–V เป็นเส้นตรงผ่านจุดกำเนิด
- ตัวนำ: ρ ต่ำ (โลหะ) / ฉนวน: ρ สูงมาก
- dc: ทิศเดียว / ac: สลับทิศ

**เลือกสูตรกำลัง:** รู้ V กับ R → V²/R / รู้ I กับ R → I²R / รู้ V กับ I → IV

## 4. ทริคทำข้อสอบให้ไว

**จัดลำดับ**
1. ทำข้อทฤษฎีก่อน (เก็บคะแนนเร็ว)
2. ข้อคำนวณ: ทำข้อที่ใช้สูตรเดียวก่อน (P = V²/R, Q = mcΔT, F_B)
3. ข้อที่ติดเกิน 2 นาที ข้ามแล้วย้อนกลับ
4. เหลือเวลา 5 นาทีสุดท้ายเช็กหน่วยกับกับดักข้อที่เคยพลาด
5. ข้อที่เดาไม่ได้ ตัดตัวเลือกที่ **ทิศผิด** ก่อน (เช่น ลูกเล็กแรงมากกว่า)

**ตัดตัวเลือกด้วยสามัญสำนึก (ช่วยเลือกได้แม้คิดไม่ออก)**
- ปาสคาล: คำตอบลูกเล็ก < แรงลูกใหญ่ เสมอ
- ท่อแคบ: v₂ > v₁ เสมอ
- น้ำผสม: T อยู่ระหว่าง T_เย็น กับ T_ร้อน
- แก๊สร้อนขึ้น (V หรือ P คงที่): อีกตัวต้อง **เพิ่ม**
- ความดันสัมบูรณ์ > P₀ เสมอ
- แรงตึงเชือกในน้ำ < น้ำหนักในอากาศ

**ทริคคิดเร็ว**
- สัดส่วนล้วนๆ (ไม่มีค่าคงที่ g, ρ) ใช้หน่วยเดิมได้ ถ้าสองฝั่งหน่วยเดียวกัน ไม่ต้องแปลงเป็น SI
- d เป็น k เท่า → A เป็น k² เท่า (R เป็น 1/k²) (v เป็น k² เท่า)
- T เป็น k เท่า (แผ่รังสี) → P เป็น k⁴ เท่า (2 เท่า → 16, 3 เท่า → 81)
- แก๊ส: ถ้ามีหลายตัวแปรเปลี่ยนพร้อมกัน ใช้ P_iV_i/T_i = P_fV_f/T_f ตัวเดียว
- แรงลอยตัวจากการชั่ง: F_B = น้ำหนักอากาศ − น้ำหนักในน้ำ แล้ว V = F_B/(ρg)
- ไม้/น้ำแข็งลอย: ใช้ V_จม/V = ρวัตถุ/ρของเหลว ตรงๆ ไม่ต้องหา F_B
- เห็น "mA", "kΩ", "นาที" → แปลงก่อนแทน

## 5. ทริคข้อประยุกต์ (ข้อสอบมักรวมหลายเรื่อง)

### 5.1 น้ำแข็งผสมน้ำ (เช็ก "ราคา vs งบ" ก่อนเสมอ)
1. ราคา = m_ice × L (ละลายหมดพอดี)
2. งบ = m_water × c × (T_water − 0)
3. **งบ < ราคา** → ละลายไม่หมด T = 0 °C, m ที่ละลาย = งบ/L
4. **งบ ≥ ราคา** → ละลายหมด ใช้สมการผสม:
   m_ice·L + m_ice·c·T = m_water·c·(T_water − T)

ถ้าได้ T ติดลบจากสมการผสม แปลว่าสมมติผิด ละลายไม่หมด

### 5.2 ของผสมสองก้อน (ไม่เปลี่ยนสถานะ)
m₁c₁(T_ร้อน − T) = m₂c₂(T − T_เย็น)  (ตัดหน่วยออกได้)

### 5.3 ท่อนำความร้อน → ละลายน้ำแข็ง (ข้อ 7 สไลด์)
P (สูตรนำ) → Q = P × t (วินาที) → m = Q/L

### 5.4 นำความร้อนต่อกันสองชั้น (ข้อ 1 สไลด์ / P1.1)
ในสภาวะคงตัว P ผ่านทั้งสองชั้นเท่ากัน:
k₁A(T_H − T)/L₁ = k₂A(T − T_C)/L₂ แล้วแก้หา T (A เท่ากันตัดได้)

### 5.5 นำ + พา (หรือ พา + แผ่รังสี) รวมกัน
สูญเสียทั้งหมด = P_นำ + P_พา (หรือ P_พา + P_แผ่) คิดแต่ละตัวแล้ว **บวกกัน**
(ตัวอย่างในสไลด์ ข้อ 3, 4)

### 5.6 วัตถุจมในของเหลว มีเชือก
- ΣF = 0: T + F_B = mg → T = mg − F_B
- วัตถุลอยแต่มีเชือกดึงลงกับก้นถัง: T = F_B − mg

### 5.7 ของเหลวหลายชั้น / มานอมิเตอร์ (ข้อ 3, 4 สไลด์)
- เขียนความดันที่ **ระดับเดียวกัน** สองฝั่งให้เท่ากัน
- เดินจากจุดหนึ่งไปอีกจุด: ลงลึก +ρgh / ขึ้นสูง −ρgh
- ข้อ 4 สไลด์: P_A − P_a = ρ_Hg·g·h_Hg + ρ_oil·g·h_oil แล้วแก้หา h_oil ระวังบวกความสูงใต้เกจ (0.05 m) ตอนท้าย

### 5.8 ความต่อเนื่อง + แบร์นูลลี (เวนจูรี / ท่อหดแคบ)
1. ความต่อเนื่อง: หา v₂ ในรูป v₁
2. แทนใน P₁ − P₂ = ½ρ(v₂² − v₁²) แล้วแก้หา v₁
3. Q = A₁v₁
(ข้อ 9 สไลด์, P2.5)

### 5.9 เติมน้ำสระ
t = V_สระ/Q_รวม ท่อ n เส้น: Q_รวม = n × Av (ปริมาตรสระ = กว้าง × ยาว × **ความสูงน้ำ**)

### 5.10 น้ำพุ่งจากรูขนานพื้น (P2.1)
- v จาก Q/A หรือ √(2gh)
- ตกถึงพื้น: เวลา t = √(2H/g), ระยะ x = v·t

### 5.11 ความดันเกจในถังอัดอากาศ (P2.6)
P_gauge = ½ρv² + ρgh (อากาศในถังดันน้ำให้พุ่งด้วย v ผ่านความสูง h)

### 5.12 ลวดยืด/เปลี่ยนรูปแล้ว R เปลี่ยน
- ปริมาตรคงที่ (ลวดยืดยาว): L เพิ่ม k เท่า → A ลด k เท่า → R เพิ่ม **k² เท่า**
- ถ้าให้ d เปลี่ยนแต่ L เท่าเดิม: R ∝ 1/d²

### 5.13 ค่าไฟ
E (kWh) = P(kW) × t(ชั่วโมง) แล้วคูณราคาต่อหน่วย

### 5.14 ตัวเลขในสไลด์ที่ไม่ตรงกับที่คำนวณ (ในห้องสอบยึดวิธีคำนวณ)
- นำความร้อนเหล็ก-ทองแดง (ตัวอย่างที่ 1): 100/4.83 = **20.7 °C** (สไลด์เขียน 26.1)
- ท่อเหล็กทรงกระบอก (ตัวอย่างที่ 2): P ≈ **3.5×10⁶ W** (สไลด์เขียน 10⁵)
- น้ำ 2 kg + ลูกเหล็ก 2 kg (80 °C กับ 25 °C): T ≈ **74.6 °C** (สไลด์เขียน 69.6)

## 6. ตารางกับดักที่พลาดซ้ำ + วิธีกัน

| กับดัก | วิธีกัน |
|---|---|
| ลืมยกกำลังสอง d | เห็น d/r → เขียน A = r² ลงกระดาษก่อน |
| ใช้ °C ในแก๊ส/แผ่รังสี | วงกลม T ทุกตัวในโจทย์ แล้ว +273 |
| ลืมกำลัง 4 ของแผ่รังสี | เห็นคำว่า "แผ่รังสี" → T⁴ |

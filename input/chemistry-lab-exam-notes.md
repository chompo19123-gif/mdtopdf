## 📏 Lab 1 การวัดทางวิทยาศาสตร์

### 🔑 นิยาม
- **เลขนัยสำคัญ** = ตัวเลขที่แน่นอน + ตัวสุดท้ายที่ประมาณด้วยสายตา (ความไม่แน่นอน)
- **ความคลาดเคลื่อนสัมบูรณ์** = ½ × สเกลเล็กที่สุด (เช่น สเกล 0.1 cm → ±0.05 cm)
- อ่านค่าที่ **ขอบเว้าล่าง (meniscus)** ให้อยู่ระดับสายตาเสมอ

### 🧰 อุปกรณ์กับรูปแบบค่าที่อ่านได้

| อุปกรณ์ | อ่านค่าแบบ | ตัวอย่าง |
|---|---|---|
| บิวเรต, ปิเปต, ไม้บรรทัด | ทศนิยม **2** ตำแหน่ง | 25.00 cm³ |
| กระบอกตวง | ทศนิยม **1** ตำแหน่ง | 26.0 cm³ |
| บีกเกอร์ | **เลขเต็ม** (ละเอียดน้อยสุด) | 25 cm³ |
| เทอร์โมมิเตอร์ | ทศนิยม 1 ตำแหน่ง | 33.0 °C |

### 🔢 นับเลขนัยสำคัญ
- ศูนย์นำหน้า **ไม่นับ** → 0.0026 = 2 ตัว
- ศูนย์ท้ายหลังจุด **นับ** → 1.2300 = 5 ตัว
- เลขยกกำลังนับเฉพาะหน้า × → 5.30 × 10³ = 3 ตัว

### ➕ กฎการคำนวณ

| การคำนวณ | ตอบตาม | ตัวอย่าง |
|---|---|---|
| ➕➖ บวก / ลบ | **ทศนิยมน้อยที่สุด** | 1.0 + 5.23 = 6.23 → **6.2** |
| ✖️➗ คูณ / หาร | **จำนวนเลขนัยน้อยที่สุด** | 4.62 / 2.0 = 2.31 → **2.3** |
| ✖️➗ คูณ / หาร | **จำนวนเลขนัยน้อยที่สุด** | 4.62 / 0.2 = 23.1 → **2 × 10¹** |

> 💡 คำนวณให้จบก่อน แล้วค่อยปัดตอนท้ายทีเดียว

### 🎯 ความถูกต้อง vs ความเที่ยง

| | 🎯 ความถูกต้อง (Accuracy) | 🔁 ความเที่ยง (Precision) |
|---|---|---|
| ความหมาย | ใกล้ **ค่าจริง** | วัดซ้ำได้ **ใกล้กัน** (ใกล้ค่าเฉลี่ย) |
| ขึ้นกับ | ประสิทธิภาพเครื่องมือ | วิธีวัด + ตัวผู้วัด |
| ความผิดพลาดที่กระทบ | เชิงระบบ (systematic) → **แก้ได้** | เชิงสุ่ม (random) → **แก้ไม่ได้** ลดได้ด้วยการวัดซ้ำ |

### 📐 สูตร
```
%error = |X̄ − R| / R × 100
d = m / V
```

- 📈 **กราฟความหนาแน่น:** m อยู่แกน y และ V อยู่แกน x → **ความชัน (slope) = d**
- V ของแข็งหาได้ 2 แบบ: กว้าง × ยาว × สูง หรือ V₂ − V₁ (แทนที่น้ำ)
- 🧪 บิวเรต/ปิเปต ต้องกลั้วด้วยสารที่จะใช้ 2 ครั้ง
- 🚫 ปิเปตต้องใช้ลูกยาง **ห้ามดูดด้วยปาก** และ **ห้ามเป่าหยดสุดท้าย**
- บิวเรตไม่จำเป็นต้องเริ่มที่ 0.00

## ⚗️ Lab 2 ร้อยละองค์ประกอบ

### 🔑 หลักการ
- เป็นการวิเคราะห์ **เชิงปริมาณโดยการชั่งน้ำหนัก (gravimetric)** ผ่านการตกตะกอน
- Ba²⁺ + SO₄²⁻ → **BaSO₄ ↓ (ตะกอนสีขาว)**
- **H₂SO₄ = สารที่ทำให้ตกตะกอน (precipitant)**
- 🔍 เชิงคุณภาพ = มี **อะไร** · 📊 เชิงปริมาณ = มี **เท่าไร**

### 🪜 ขั้นตอน
1. ชั่งตัวอย่าง 1–2 g → ละลายใน **น้ำร้อน** ~50 cm³
2. เติม **8 M HCl** 1 cm³ → ค่อยๆ เติม **3 M H₂SO₄** 8 cm³ พร้อมกวน (ตะกอนเกิดทันที)
3. ปิดกระจกนาฬิกา ต้มเกือบเดือดจนตะกอนนอนก้น
4. พับกระดาษกรอง (เขียนชื่อด้วย **ดินสอ**) และชั่งคู่กับกระจกนาฬิกา
5. **Decantation** → รินส่วนใสผ่านแท่งแก้ว แล้วกรอง
6. ล้างตะกอนด้วย **น้ำกลั่น** 2 ครั้ง → ตามด้วย **อะซิโทน** (ให้แห้งเร็ว)
7. อบที่ 80 °C → ตั้งใน **หม้อดูดความชื้น** จนเย็น → ชั่ง

### ❓ ทำไม (ออกบ่อย)
- HCl + ความร้อน + กวน → ตกตะกอนช้าลง → **ได้ผลึกใหญ่ กรองง่าย สารมลทินน้อย**
- กรองขณะร้อน หรือให้ปลายกรวยแตะข้างบีกเกอร์ → **กรองเร็วขึ้น**
- อย่าปล่อยให้กระดาษกรองแห้งระหว่างกรอง
- ล้างหลายครั้งครั้งละน้อย ดีกว่าล้างครั้งเดียวปริมาณมาก
- การล้างทำให้ตะกอน **บริสุทธิ์ขึ้น แต่ปริมาณลดลง**
- 🚫 ไม่ใช้เอทานอล และไม่มีบัฟเฟอร์
- ถ้ามีไอออนอื่นที่ตกตะกอนกับ SO₄²⁻ ได้ด้วย → **หา %Ba ไม่ได้**

### ⚠️ ผลของความผิดพลาด

| ความผิดพลาด | %Ba ที่ได้ |
|---|:---:|
| ตะกอนไม่แห้ง / ล้างไม่สะอาด / ไม่เข้าหม้อดูดความชื้น | ⬆️ สูงเกินจริง |
| กระดาษกรองรั่ว / ตะกอนหก / ตกตะกอนไม่หมด | ⬇️ ต่ำกว่าจริง |

### 📐 สูตร
```
m(Ba) = m(BaSO₄) × 137.33 / 233.39
%Ba   = m(Ba) / m(ตัวอย่าง) × 100
```

> ✏️ **ตัวอย่าง:** ได้ BaSO₄ 0.466 g จากตัวอย่าง 10 g
> Ba = 137 × 0.466 / 233 = 0.274 g → %Ba = 0.274 / 10 × 100 = **2.74%**

- %Ba ใน BaCl₂·2H₂O = **56.23%**
- แร่เหล็กที่มี %Fe มากที่สุดคือ **FeO**

## 💧 Lab 3 เทคนิคการไทเทรต

การไทเทรต = **การวิเคราะห์โดยปริมาตร (volumetric analysis)** ใช้หาความเข้มข้นของสารตัวอย่าง

### 📖 คำศัพท์

| คำ | ความหมาย |
|---|---|
| 🧪 ไทแทรนต์ (titrant) | สารใน **บิวเรต** ปกติเป็นสารมาตรฐานที่รู้ความเข้มข้น |
| 🍶 ไทเทรนด์ (titrand / analyte) | สารใน **ขวดรูปชมพู่** รู้ปริมาตรแต่ไม่รู้ความเข้มข้น |
| ⚖️ จุดสมมูล | mol กรด = mol เบส ตามสมการ (จุดทางทฤษฎี มองไม่เห็น) |
| 🎨 จุดยุติ | จุดที่ **อินดิเคเตอร์เปลี่ยนสี** (ใกล้จุดสมมูลแต่ไม่เท่ากัน) |
| 🌈 อินดิเคเตอร์ | สีย้อมที่เปลี่ยนสีตาม pH ใช้บอก **จุดยุติ** |
| 🥇 สารมาตรฐานปฐมภูมิ | บริสุทธิ์สูง เสถียร ไม่ดูดความชื้น มวลโมเลกุลสูง (เช่น HCl 0.05000 M, KHP) |
| 🥈 สารมาตรฐานทุติยภูมิ | บริสุทธิ์ไม่พอ ต้อง **เทียบมาตรฐาน (standardize)** กับสารปฐมภูมิก่อน เช่น **NaOH** |

### 🧫 การทดลอง 2 ตอน
1. **เทียบมาตรฐาน NaOH** (อยู่ในบิวเรต) ด้วย HCl 0.05000 M 10.00 cm³ (อยู่ในขวดรูปชมพู่)
   > 📌 ข้อยกเว้น: ตอนนี้สารมาตรฐานอยู่ในขวดรูปชมพู่
2. ใช้ NaOH ไทเทรต **กรดตัวอย่าง H₂SO₄** 10.00 cm³
   ทำ 3 ขวดแล้วหาค่าเฉลี่ย

### 🌈 อินดิเคเตอร์

| อินดิเคเตอร์ | ช่วง pH | สีที่เปลี่ยน |
|---|:---:|---|
| methyl red | 4.2–6.3 | 🔴 แดง → 🟡 เหลือง |
| bromothymol blue | 6.0–7.6 | 🟡 เหลือง → 🔵 น้ำเงิน |
| ⭐ **phenolphthalein** (ใช้ในแลป, 2 หยด) | **8.3–10.0** | ⚪ ไม่มีสี → 🩷 **ชมพูบานเย็น** |

- กรดแก่ + เบสแก่ → จุดสมมูลมี **pH = 7**
- จุดยุติของฟีนอลฟทาลีน ≈ 8.5
- หยุดเมื่อสีชมพูจาง ๆ คงอยู่ **นานกว่า 15 วินาที**
- บันทึกค่าทศนิยม 2 ตำแหน่ง

### ✅❌ ทำถูก / ทำผิด
- ✅ กลั้วบิวเรต/ปิเปตด้วยสารที่จะใช้
- ✅ ฉีดน้ำกลั่นชะข้างขวดระหว่างไทเทรต **ได้ และไม่ทำให้ผลผิด** (จำนวนโมลไม่เปลี่ยน)
- ❌ กลั้วขวดรูปชมพู่ด้วยสารที่จะใส่
- ❌ ใส่อินดิเคเตอร์มากเกินไป หรือใส่ลงในบิวเรต
- ❌ ใช้ไทแทรนต์ **เกิน 1 บิวเรต** (50 cm³) → แก้ได้โดยลดปริมาตรตัวอย่าง หรือใช้ไทแทรนต์ที่เข้มข้นขึ้น

### 📐 สูตร
```
a·C(กรด)·V(กรด) = b·C(เบส)·V(เบส)
H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O
```
- a = จำนวน H⁺ (HCl = 1, **H₂SO₄ = 2**)
- b = จำนวน OH⁻ (NaOH = 1)

> ✏️ **ตัวอย่าง:** H₂SO₄ 10 mL ใช้ 0.5 M NaOH 20 mL
> 2(C)(10) = (0.5)(20) → **C = 0.5 M**

- ถ้าใช้ NaOH ปริมาตรเท่ากับ H₂SO₄ → [H₂SO₄] = **½ [NaOH]**

## 🚰 Lab 4 ความกระด้างของน้ำ

### 🔑 หลักการ
- น้ำกระด้าง = มี **Ca²⁺, Mg²⁺** (ไอออนบวกประจุมากกว่า +1) → เกิดตะกรัน **CaCO₃**
- รายงานในหน่วย **mg CaCO₃/L = ppm**
- หาโดย **ไทเทรตแบบเกิดสารเชิงซ้อนกับ EDTA**

### 🔀 ชนิดความกระด้าง

| ชนิด | ไอออนลบที่มาด้วย | วิธีกำจัด |
|---|---|---|
| ⏳ ชั่วคราว (carbonate) | HCO₃⁻, CO₃²⁻ | 🔥 **ต้ม** หรือเติมปูนขาว Ca(OH)₂ |
| 🧱 ถาวร (non-carbonate) | Cl⁻, SO₄²⁻ | ต้มไม่หาย → **แลกเปลี่ยนไอออน / water softener** |

### 📊 ระดับความกระด้าง

| ระดับ | ppm CaCO₃ |
|---|:---:|
| 💧 น้ำอ่อน | 0–75 |
| 🟢 กระด้างน้อย | 75–150 |
| 🟡 กระด้างปานกลาง | 150–300 |
| 🔴 กระด้างมาก | > 300 |

### 🧪 บทบาทของสารแต่ละตัว

| สาร | หน้าที่ |
|---|---|
| EDTA (อยู่ในบิวเรต) | สารมาตรฐานที่ไทเทรต จับ Ca²⁺/Mg²⁺ ในอัตราส่วน **1 : 1** |
| Ca²⁺ จาก CaCO₃ | สารมาตรฐาน **ปฐมภูมิ** ใช้หาความเข้มข้นแน่นอนของ EDTA |
| Eriochrome black T (EBT) | **อินดิเคเตอร์** |
| บัฟเฟอร์ NH₃/NH₄NO₃ | ควบคุม **pH 10** (ปฏิกิริยาให้ H⁺ และกัน Fe³⁺ รบกวน) |
| MgCl₂ 0.03 M 8 หยด | ช่วยให้อินดิเคเตอร์เปลี่ยนสีชัด · ใช้ทำ **blank** · ต้องเติมเท่ากันทุกครั้ง |

### 🎨 จุดยุติ
**🟣 ม่วงแดง (MgIn⁻) → 🔵 น้ำเงินใส (HIn²⁻ อิสระ)**

### 🪜 3 ขั้นตอน
1. **Blank** (น้ำกลั่น + MgCl₂) → ปริมาตร [A]
2. **เทียบมาตรฐาน** ด้วย Ca²⁺ → ปริมาตร [B]
3. **น้ำตัวอย่าง** → ปริมาตร [C]

> 📌 ปริมาตรจริง = **[B] − [A]** และ **[C] − [A]**

### 📐 สูตร
```
mol EDTA = mol CaCO₃ = C × V(EDTA) / 1000
mg CaCO₃ = mol × 100 × 1000
ppm      = mg / L ของน้ำตัวอย่าง
```

> ✏️ **ตัวอย่าง:** น้ำ 10.00 cm³ ใช้ 0.002 M EDTA 20.00 cm³
> mol = 4.0 × 10⁻⁵ → 4.0 mg → 4.0 / 0.0100 L = **400 ppm 🔴 กระด้างมาก**

- ⚠️ ถ้าโจทย์ให้ ppm ของ Ca²⁺ มา ต้อง × 100/40 ก่อน แล้วจึงเทียบระดับ

## ⚖️ Lab 5 สมดุลเคมี

### 🔑 หลักการ
- สมดุลเคมีเป็น **สมดุลไดนามิก** คืออัตราไปข้างหน้า = อัตราย้อนกลับ
- ปฏิกิริยาไม่หยุด แต่สมบัติ (สี ความเข้มข้น) คงที่

### 📐 ค่าคงที่สมดุล
```
aA + bB ⇌ cC + dD
Kc = [C]^c [D]^d / [A]^a [B]^b
```
- 🚫 ไม่ใส่ **ของแข็ง (s)** และ **ของเหลวบริสุทธิ์** ลงใน K
- สมการ × 2 → **K²** · กลับสมการ → **1/K**
- 🌡️ **อุณหภูมิเป็นตัวเดียวที่เปลี่ยนค่า K**
- ตัวเร่งไม่เลื่อนสมดุลและไม่เปลี่ยน K

### 🔄 หลักเลอชาเตอลิเย
> รบกวนอะไร ระบบจะเลื่อนไปทางที่ลดสิ่งนั้น (ปัจจัยคือ ความเข้มข้น อุณหภูมิ ความดัน)

| รบกวน | สมดุลเลื่อนไป |
|---|:---:|
| เติมสารซ้าย / ดึงสารขวาออก | ➡️ ขวา |
| เติมสารขวา / ดึงสารซ้ายออก | ⬅️ ซ้าย |
| 🔥 เพิ่ม T | ทาง **ดูด** ความร้อน |
| ❄️ ลด T | ทาง **คาย** ความร้อน |

- ปฏิกิริยาดูดความร้อน: T↑ → **K↑**
- ปฏิกิริยาคายความร้อน: T↑ → **K↓**
- 💡 เทคนิค: เขียน "ความร้อน" เป็นสารตัวหนึ่งในสมการ

### 🎨 ระบบโคบอลต์ที่ทำในแลป (ปฏิกิริยาดูดความร้อน)
```
[Co(H₂O)₆]²⁺  +  4Cl⁻  ⇌  [CoCl₄]²⁻  +  6H₂O
 🩷 ชมพู, octahedral        🔵 น้ำเงิน, tetrahedral
```

| ทำอะไร | สีที่ได้ |
|---|---|
| เติม conc. HCl | 🔵 น้ำเงิน |
| เติมน้ำ | 🩷 ชมพู |
| แช่น้ำร้อน 80–90 °C | 🔵 น้ำเงิน |
| แช่น้ำแข็ง 0 °C | 🩷 ชมพู |
| อุณหภูมิห้อง | 🟣 ม่วง |

- ผลึก CoCl₂·6H₂O สีม่วง · Co(NO₃)₂·6H₂O สีส้ม (เพราะไอออนลบต่างกัน)
- ในเอทานอล/อะซิโทน Cl⁻ แทนที่ได้ **ดีกว่า** ในน้ำ → ใช้ HCl น้อยกว่า และสีน้ำเงินเข้มกว่า
- 🚫 **ความดันไม่มีผล** กับระบบนี้ (ไม่มีแก๊ส)

## 🔥 Lab 6 ความร้อนของปฏิกิริยา

### 🔑 หลักการ
- แคลอริมิเตอร์ในแลปเป็นแบบ **ความดันคงที่ (coffee cup)** → q = **ΔH**
- แบบปริมาตรคงที่ → q = ΔU
- 🔥 คายความร้อน ΔH < 0 (ภาชนะร้อน) · ❄️ ดูดความร้อน ΔH > 0 (ภาชนะเย็น)
- **q = m·s·ΔT** (s ของน้ำ = 1 cal/g·°C)
- **q = C·ΔT** (C มีหน่วย cal/°C)
- 🧰 อุปกรณ์: ถ้วยพลาสติกหุ้มโฟม แท่งกวน เทอร์โมมิเตอร์ (🚫 ไม่ใช้กระจกนาฬิกา)
- 📈 **อุณหภูมิผสม:** พล็อต T (แกน y) กับเวลา (แกน x) แล้ว **ลากเส้นย้อนกลับไปที่ t = 0** เพราะปฏิกิริยาเร็วจนเทอร์โมมิเตอร์วัดไม่ทัน
- ต้องหา C_cal **ทุกครั้งและทุกตัว** เพราะแคลอริมิเตอร์แต่ละตัวรับความร้อนไม่เท่ากัน

### 1️⃣ ตอนที่ 1 หา C_cal
> ความร้อนที่น้ำร้อนเสีย = ความร้อนที่น้ำเย็นได้รับ + ความร้อนที่แคลอริมิเตอร์ได้รับ
```
m_ร้อน·s·(T_ร้อน − T_ผสม) = m_เย็น·s·(T_ผสม − T_เย็น) + C_cal·(T_ผสม − T_เย็น)
```
> ✏️ **ตัวอย่าง:** 20(1)(70 − 40) = 20(1)(40 − 25) + C(15)
> 600 = 300 + 15C → **C = 20 cal/°C**

### 2️⃣ ตอนที่ 2 หา ΔH ของปฏิกิริยาสะเทิน
- ใช้ 5 M HCl 24.00 cm³ + 5 M NaOH 25.0 cm³ → **HCl เป็นสารกำหนดปริมาณ**
- 🚫 ไม่ใช้อินดิเคเตอร์
- s ของ NaCl = 0.860 cal/g·°C
```
q        = m(สารละลาย)·s·ΔT + C_cal·ΔT
mol H₂O  = mol HCl = C × V / 1000
ΔH_neut  = q / mol H₂O
```

> ⚠️ **mol H₂O = mol HCl** ห้ามเอามวลสารละลายหาร 18

- 📌 ค่าทฤษฎี = **−13.7 kcal/mol H₂O** (H⁺ + OH⁻ → H₂O) ไม่ขึ้นกับชนิดของกรดแก่/เบสแก่
- คู่ที่ใช้ในแลป = **HCl + NaOH**
- ความร้อนสะเทิน **ใช้หาความเข้มข้นของกรดได้** (q → mol → C)
- ก่อนทดลองให้กลั้วด้วยน้ำก๊อกจนแคลอริมิเตอร์เท่ากับอุณหภูมิห้อง
- 🔤 สูตรตัวอักษร: แก๊ส A g (มวลโมเลกุล D) ทำให้น้ำ B g ร้อนขึ้น C °C → q ต่อโมล = **BCD/A**

## 🔋 Lab 7 ไฟฟ้าเคมี

### ⚡ แอโนด vs แคโทด

| | ➖ แอโนด | ➕ แคโทด |
|---|---|---|
| ขั้ว | **ลบ (−)** | **บวก (+)** |
| ปฏิกิริยา | ออกซิเดชัน (ให้ e⁻) | รีดักชัน (รับ e⁻) |
| E° | น้อยกว่า | มากกว่า |
| สิ่งที่เห็น | โลหะผุกร่อน | โลหะมาเกาะ |
| ตำแหน่งในแผนภาพ | ซ้ายของ // | ขวาของ // |

> 🔁 e⁻ ไหลจากแอโนดไปแคโทดผ่านลวด

### 📋 ค่าศักย์รีดักชันมาตรฐาน

| ครึ่งเซลล์ | E° (V) |
|---|:---:|
| Ag⁺/Ag | +0.80 |
| Cu²⁺/Cu | +0.34 |
| H⁺/H₂ | 0.00 |
| Pb²⁺/Pb | −0.126 |
| Zn²⁺/Zn | −0.76 |
| Mg²⁺/Mg | −2.38 |

- ตัวออกซิไดซ์: **Cu²⁺ > Pb²⁺ > Zn²⁺**
- ตัวรีดิวซ์: **Zn > Pb > Cu**
- เลขออกซิเดชันลด = รีดักชัน = เป็น **ตัวออกซิไดซ์**
- 🧪 จุ่มโลหะลงสารละลาย: เกิดปฏิกิริยาเมื่อ **E° โลหะ < E° ไอออน**
  - ✅ Zn ใน Cu²⁺ · ✅ Pb ใน Cu²⁺ · ❌ Cu ใน Zn²⁺
- โลหะที่ไม่ผุกร่อนในกรด = **Cu**
- โลหะในแลป: Pb, Zn, Cu (🚫 ไม่ใช้ Sn) ต้องขัดด้วยกระดาษทรายเพื่อกำจัดออกไซด์ก่อน
- 🌉 สะพานไอออน = กระดาษชุ่ม **1 M KNO₃** ทำหน้าที่ **รักษาสมดุลประจุไอออน** (เป็นทางเดินของไอออน ไม่ใช่ e⁻) ต้องเปลี่ยนใหม่ทุกชุด
- 📟 วัดด้วยมัลติมิเตอร์ตั้ง DC 20 V ใช้เสร็จแล้วหมุนไป OFF
- เซลล์กัลวานิกเกิดขึ้นเองได้ ไม่ต้องจ่ายไฟ

### 📐 สูตร
```
E°cell = E°(แคโทด) − E°(แอโนด)   = ขวา − ซ้าย
E      = E° − (0.0592/n) log Q
       = E° − (RT/nF) ln Q        (T = 298 K, R = 8.314, F = 96,500)
```
- Q = [ไอออนฝั่งแอโนด] / [ไอออนฝั่งแคโทด] เช่น [Zn²⁺]/[Cu²⁺]
- n = 2 สำหรับ Zn, Cu, Pb
- ✅ **E° > 0 = เกิดขึ้นเองได้**

### 🔢 ค่าที่ต้องจำ

| เซลล์ | E° (V) |
|---|:---:|
| Zn // Cu | **1.10** |
| Zn // Pb | **0.634** |
| Pb // Cu | **0.466** |
| Cu // Zn (เขียนกลับด้าน) | **−1.10** (ไม่เกิดเอง) |

- ไอออนฝั่งแอโนดเจือจางลง → E **เพิ่มขึ้น** (Zn²⁺ 0.1 M → 1.1295 V, 0.01 M → 1.159 V)
- 🔋 **เซลล์ความเข้มข้น** = ขั้วชนิดเดียวกันแต่ความเข้มข้นต่างกัน
  - E° = 0
  - ฝั่งที่เข้มข้นสูงกว่าเป็นขั้วบวก
  - ความเข้มข้นต่างกันมาก → E มาก
  - ที่สมดุล E = 0
- ค่าที่วัดคลาดเคลื่อนเพราะอุณหภูมิ/ความเข้มข้นไม่คงที่ (ไม่ใช่เพราะน้ำหนักแท่งโลหะ)

## 🔬 Lab 8 การวิเคราะห์ไอออน 8 ตัว

> ⚠️ **ต้องท่องให้ครบทั้ง 8 ตัว** รวม PO₄³⁻, CrO₄²⁻, SCN⁻ ด้วย เพราะออกสอบทุกชุด

| ไอออน | รีเอเจนต์ | ✅ ผลบวก |
|---|---|---|
| CO₃²⁻ | HCl | 🫧 ฟองแก๊ส CO₂ ไม่มีสีไม่มีกลิ่น (ทำน้ำปูนใสขุ่น) |
| SO₄²⁻ | HCl + BaCl₂ | ⚪ ตะกอนขาว BaSO₄ |
| Cl⁻ | HNO₃ + AgNO₃ | ⚪ ตะกอนขาว AgCl |
| PO₄³⁻ | HNO₃ + (NH₄)₂MoO₄ | 🟡 ตะกอนสีเหลือง |
| CrO₄²⁻ | HNO₃ + H₂O₂ | 🔵 สารละลายสีฟ้า/น้ำเงิน (Cr₂O₅) |
| SCN⁻ | CH₃COOH + Fe(NO₃)₃ | 🔴 สีแดงเลือด [Fe(SCN)ₓ]ʸ |
| CH₃COO⁻ | H₂SO₄ (3 M) | 👃 กลิ่นน้ำส้มสายชู |
| NH₄⁺ | NaOH | 💨 แก๊ส NH₃ → ลิตมัสแดงเป็นน้ำเงิน |

### 🗂️ จัดกลุ่มตามสิ่งที่เห็น (โจทย์ "ยกเว้น" ชอบถาม)
- 🧱 **เกิดตะกอน:** SO₄²⁻, Cl⁻ (ขาว) · PO₄³⁻ (เหลือง)
- 💨 **เกิดแก๊ส/กลิ่น:** CO₃²⁻, CH₃COO⁻, NH₄⁺
- 🎨 **สารละลายเปลี่ยนสี:** CrO₄²⁻, SCN⁻

### 🧪 Blank vs Control

| | ใส่อะไร | ถ้าตัวอย่างให้ผลเหมือนหลอดนี้ |
|---|---|---|
| **Blank test** | น้ำกลั่น 1 cm³ + รีเอเจนต์ | ❌ **Negative** (ไม่มีไอออนนั้น) |
| **Control test** | สารละลายไอออนนั้น 1 cm³ + รีเอเจนต์ | ✅ **Positive** (มีไอออนนั้น) |

### ⚠️ การรบกวน
- น้ำประปามี Cl⁻ → รบกวนการตรวจ Cl⁻ ต้องชะหลอดด้วยน้ำกลั่นก่อน
- SCN⁻ รบกวนการตรวจ Cl⁻ (เกิด AgSCN สีขาว) → กำจัดโดยต้มกับ HNO₃
- สิ่งที่สังเกต: ตะกอน แก๊ส สี กลิ่น — 🚫 **ไม่ใช่ความร้อน**
- ไอออนที่ **ไม่มี** ในแลป: Br⁻, OH⁻, HCO₃⁻
- ถ้าปฏิกิริยาช้า → กวนหรือแช่น้ำร้อน (🚫 ห้ามลนไฟตรง)
- ↑ = เกิดแก๊ส · ↓ = เกิดตะกอน
- สารตัวอย่างต้องเป็น **สารไอออนิก** ที่ละลายน้ำได้

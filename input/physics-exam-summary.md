# 📘 สรุปอ่านก่อนสอบ: ฟิสิกส์ (ความร้อน / ของไหล / ไฟฟ้ากระแส)

> อ่านไฟล์นี้ก่อนเข้าห้องสอบ 15-20 นาที แบ่งเป็น 4 ส่วน: ค่าที่ต้องจำ → สูตรแต่ละเรื่อง → ทริคทำเร็ว → กับดักที่โดนหักคะแนน

## 🔥 ส่วนที่ 1: ความร้อน

### 1.1 นิยามที่ต้องตอบได้
- **พลังงานความร้อน** = พลังงานจลน์ **รวม** ของอนุภาค
- **อุณหภูมิ** = พลังงานจลน์ **เฉลี่ย** ของอนุภาค
- **ความร้อน** = พลังงานความร้อนที่เคลื่อนที่จากร้อน → เย็น

### 1.2 การส่งผ่านความร้อน

| แบบ | ตัวกลาง | สูตร |
|---|---|---|
| นำความร้อน | ของแข็ง (สัมผัสตรง) | P = kAΔT/L |
| พาความร้อน | ของเหลว/แก๊ส | P = hAΔT |
| แผ่รังสี | ไม่ต้องมี | P_net = eσA(T_h⁴ − T_c⁴) |

**นำความร้อนรูปทรงต่างๆ**
- ทรงกระบอกกลวง: **P = 2πkL(T₁−T₂) / ln(r₂/r₁)**
- ทรงกลมกลวง: **P = 4πk(T₁−T₂) · r₁r₂/(r₂−r₁)**
- แผ่นต่อกันหลายชั้น: **P เท่ากันทุกชั้น** → ตั้งสมการแต่ละชั้นให้เท่ากัน

**โจทย์รวม:**
- นำ + พา → P รวม = P_นำ + P_พา (เช่น ภาชนะทรงกลมมีน้ำร้อนข้างใน)
- พา + รังสี → P รวม = P_พา + P_รังสี (เช่น โลหะร้อนวางในห้อง)

### 1.3 ความร้อนกับสสาร
- เปลี่ยนอุณหภูมิ: **Q = mcΔT**
- เปลี่ยนสถานะ (อุณหภูมิคงที่): **Q = mL**
- ผสมกัน: **ความร้อนที่เสีย = ความร้อนที่ได้รับ**
- ถ้าโจทย์ให้กำลัง P แล้วถามเวลา: **t = Q/P**

### 1.4 แก๊สอุดมคติ
- **PV = nRT** โดย n = m/M (M หน่วย **kg/mol**) หรือ n = N/N_A
- **PV = Nk_BT** (ใช้เมื่อโจทย์ให้จำนวนโมเลกุล)
- **P₁V₁/T₁ = P₂V₂/T₂** (กฎรวม)

| กฎ | อะไรคงที่ | สูตร |
|---|---|---|
| บอยล์ | T | P₁V₁ = P₂V₂ |
| ชาร์ลส์ | P | V₁/T₁ = V₂/T₂ |
| เก-ลุสแซก | V | P₁/T₁ = P₂/T₂ |
| อาโวกาโดร | P, T | V₁/n₁ = V₂/n₂ |
| ดาลตัน | – | P_total = P₁ + P₂ + ... |

### 1.5 ⚡ ทริคความร้อน
1. **โจทย์น้ำแข็งผสมน้ำ ให้เช็กก่อนเสมอ:**
   - Q ละลายหมด = mL
   - Q สูงสุดที่น้ำปล่อยได้ถึง 0°C = mcΔT
   - น้ำปล่อยได้ **น้อยกว่า** → ละลายไม่หมด **T = 0°C** แล้ว m_ที่ละลาย = Q/L
   - น้ำปล่อยได้ **มากกว่า** → ละลายหมด แล้วค่อยตั้งสมการหา T
2. **สูตรที่ใช้ "ผลต่างอุณหภูมิ" (นำ, พา, mcΔT) ใช้ °C ได้เลย** ไม่ต้องแปลงเป็น K
3. **สูตรรังสีและแก๊สต้องแปลงเป็น K ทุกครั้ง**
4. โจทย์แผ่นต่อกัน ถ้าพื้นที่เท่ากัน **ตัด A ทิ้งได้** ลดเลขลง
5. ท่อ/ทรงกลมหนาบาง: ระวังว่า r₂ = r₁ + ความหนา
6. ความดัน/ปริมาตรที่เป็นอัตราส่วน (P₁V₁/T₁ = P₂V₂/T₂) **ไม่ต้องแปลงหน่วย** ถ้าสองข้างใช้หน่วยเดียวกัน (แต่ T ต้องเป็น K)

## 🌊 ส่วนที่ 2: กลศาสตร์ของไหล

### 2.1 ความหนาแน่นและความดัน
- **ρ = m/V**
- ความถ่วงจำเพาะ = ρ_สาร / ρ_น้ำ
- **P = F/A** (หน่วย Pa = N/m²)
- **P = P₀ + ρgh** (ความดันสัมบูรณ์ที่ความลึก h)
- ความดันเกจ **P_g = P − P₀ = ρgh**
- ผลต่างความดัน: **P₂ − P₁ = ρg(h₂ − h₁)**
- ของเหลวหลายชั้น: บวกความดันทีละชั้น

### 2.2 เครื่องวัดความดัน
- **บารอมิเตอร์:** P₀ = ρ_Hg · g · h (1 atm ≈ 0.76 m ปรอท)
- **มานอมิเตอร์ (หลอดตัว U):** จุดที่ **ระดับเดียวกัน ของเหลวเดียวกัน** ความดันเท่ากัน

### 2.3 ปาสคาล (ไฮดรอลิก)
- **F₁/A₁ = F₂/A₂**
- **A₁Δx₁ = A₂Δx₂** (ปริมาตรที่ถูกกด = ปริมาตรที่ถูกยก)

### 2.4 แรงลอยตัว (อาร์คีมีดีส)
- **F_B = ρ_ของเหลว · V_ส่วนที่จม · g** = น้ำหนักของของเหลวที่ถูกแทนที่
- **วัตถุลอย:** F_B = W → **V_จม/V_ทั้งก้อน = ρ_วัตถุ/ρ_ของเหลว**
- **จมทั้งก้อน:** V_จม = V_วัตถุ
- **ชั่งในน้ำ:** น้ำหนักที่อ่านได้ = W − F_B → **F_B = W_อากาศ − W_น้ำ**
- ρ_วัตถุ > ρ_ของเหลว → จม / น้อยกว่า → ลอย / เท่ากัน → ลอยปริ่ม

### 2.5 ของไหลเคลื่อนที่ (อุดมคติ)
**เงื่อนไข:** ไม่มีความหนืด, ไหลคงตัว (ราบเรียบ), ไม่หมุนวน, ความหนาแน่นคงที่

- **ความต่อเนื่อง: A₁v₁ = A₂v₂** (Q = Av = V/t หน่วย m³/s)
- **แบร์นูลลี: P₁ + ½ρv₁² + ρgy₁ = P₂ + ½ρv₂² + ρgy₂**

### 2.6 ⚡ ทริคของไหล
1. **หาความเร็วน้ำพุ่งออกจากรูข้างถัง** (ผิวน้ำเปิด P₁ = P₂ = P₀, v₁ ≈ 0): **v = √(2gh)** โดย h = ความลึกจากผิวน้ำถึงรู
2. **น้ำพุ่งในแนวราบแล้วตกพื้น:** เวลาตก t = √(2H/g) (H = สูงจากพื้น) ระยะแนวราบ x = v·t
3. **ท่อแนวราบ:** y₁ = y₂ ตัด ρgy ทิ้ง เหลือ P₁ + ½ρv₁² = P₂ + ½ρv₂²
4. **ท่อแคบ = เร็ว = ความดันต่ำ** (ใช้เช็กคำตอบ)
5. **A = πr² = πd²/4** ถ้าโจทย์ให้เส้นผ่านศูนย์กลาง อย่าลืมหารสองก่อนยกกำลัง หรือใช้ d²/4
6. **ปาสคาลมีพื้นที่เป็นวงกลม:** F₁/F₂ = r₁²/r₂² (ไม่ต้องคูณ π ตัดกัน)
7. **ลอยแล้วถามความลึก:** h_จม = H × (ρ_วัตถุ/ρ_ของเหลว) ถ้าเป็นแท่งสี่เหลี่ยมที่พื้นที่หน้าตัดเท่ากันตลอด
8. **ความดันเกจ vs สัมบูรณ์:** ถ้าโจทย์ให้ "ความดันที่ก้นสระ" ถ้าไม่บอกว่าเกจ ให้ใส่ P₀ ด้วย

## ⚡ ส่วนที่ 3: ไฟฟ้ากระแส

### 3.1 นิยามและสูตรหลัก
- **EMF** = ความต่างศักย์สูงสุดระหว่างขั้วแบตเตอรี่ (หน่วย V)
- **I = Δq/Δt** (หน่วย A = C/s)
- **J = I/A** (ความหนาแน่นกระแส หน่วย A/m²)
- ทิศกระแสตามข้อตกลง: **บวก → ลบ** (อิเล็กตรอนวิ่งสวนทาง)
- **DC** ทิศเดียว / **AC** สลับทิศ
- **กฎโอห์ม: V = IR** (วัสดุ Ohmic กราฟ I-V เป็นเส้นตรง)
- **R = ρL/A** (ρ = ความต้านทานจำเพาะ หน่วย Ω·m)
- **R = R₀[1 + α(T − T₀)]** และ **ρ = ρ₀[1 + α(T − T₀)]**

### 3.2 กำลังและพลังงาน
- **P = IV = I²R = V²/R**
- **E = Pt**
- **1 kWh = 3.6×10⁶ J** (kWh คือหน่วยพลังงาน)

### 3.3 กระแสสลับ
- **V_rms = V_max/√2**, **I_rms = I_max/√2** (V_max = V_rms × √2 ≈ 1.414 V_rms)
- **P_เฉลี่ย = ½ I₀V₀ = I_rms V_rms = V_rms²/R**
- ไฟบ้านที่บอกว่า 220 V คือ **ค่า rms**

### 3.4 แถบสีตัวต้านทาน
ดำ 0 / น้ำตาล 1 / แดง 2 / ส้ม 3 / เหลือง 4 / เขียว 5 / น้ำเงิน 6 / ม่วง 7 / เทา 8 / ขาว 9
แถบ 1-2 = เลข, แถบ 3 = ×10ⁿ, แถบ 4 = ทอง ±5% / เงิน ±10%

### 3.5 ⚡ ทริคไฟฟ้า
1. **เลือกสูตรกำลังตามที่โจทย์ให้:** มี V กับ R → V²/R / มี I กับ R → I²R / มี V กับ I → IV
2. **ลวดเปลี่ยนขนาด:** R ∝ L/A ดังนั้นยาวขึ้น 2 เท่า R เพิ่ม 2 เท่า / พื้นที่เพิ่ม 2 เท่า R ลดครึ่ง / **รัศมีเพิ่ม 2 เท่า R ลด 4 เท่า**
3. **ลวดถูกดึงยืดยาวขึ้น (ปริมาตรคงที่):** L เพิ่ม n เท่า → A ลด n เท่า → R เพิ่ม **n² เท่า**
4. **ประจุจากจำนวนอนุภาค:** q = Ne แล้วหา I = q/t
5. **คิดค่าไฟ:** พลังงาน (kWh) = กำลัง (kW) × เวลา (ชั่วโมง) ไม่ต้องแปลงเป็นจูล
6. **AC หาค่าสูงสุดจาก rms** ให้คูณ √2 / หากำลังเฉลี่ยให้ใช้ค่า rms

## 🚨 ส่วนที่ 4: กับดักที่โดนหักคะแนนบ่อย (เช็กก่อนส่งข้อสอบ)

### หน่วย
- [ ] °C เป็น K ในสูตรรังสีและแก๊สหรือยัง (+273)
- [ ] M เป็น kg/mol (ไม่ใช่ g/mol)
- [ ] atm เป็น Pa (× 1.013×10⁵)
- [ ] cm, mm, nm เป็น m / cm² เป็น m² / ลิตรเป็น m³ (1 L = 10⁻³ m³)
- [ ] mA เป็น A / ชั่วโมงเป็นวินาที (× 3600)
- [ ] ใช้รัศมี ไม่ใช่เส้นผ่านศูนย์กลาง

### แนวคิด
- [ ] น้ำแข็งละลายหมดไหม (เช็กก่อนตั้งสมการ)
- [ ] ความดันที่ถามคือเกจหรือสัมบูรณ์
- [ ] h ในสูตร ρgh วัดจากผิวของเหลวลงมา
- [ ] ทรงกระบอกลืมหาร ln(r₂/r₁)
- [ ] ค่า "220 V" ของไฟบ้านคือ rms
- [ ] แบร์นูลลีลืมพจน์ ρgy ตอนท่อต่างระดับ

### ตรวจคำตอบเร็วๆ (sanity check)
- อุณหภูมิสุดท้ายของการผสม ต้องอยู่ **ระหว่าง** อุณหภูมิเริ่มต้นสองอัน
- ท่อแคบลง ความเร็วต้องมากขึ้น ความดันต้องน้อยลง
- ความดันยิ่งลึกต้องยิ่งมาก
- แรงลอยตัวต้องไม่มากกว่าน้ำหนักของของเหลวปริมาตรเท่ากับวัตถุ
- ความต้านทานของโลหะมักมีค่าน้อย (หลักโอห์มหรือต่ำกว่า)

## ⏱️ แผนทำข้อสอบให้ทัน

1. **สแกนข้อสอบ 2 นาทีแรก** ทำข้อที่ "เห็นปุ๊บรู้สูตรปั๊บ" ก่อน (เช่น โอห์ม, P = ρgh, Q = mcΔT)
2. **เขียนข้อมูลที่โจทย์ให้ พร้อมแปลงหน่วยทันที** ก่อนเริ่มคำนวณ ลดความผิดพลาดมากสุด
3. **เขียนสูตรก่อนแทนค่าเสมอ** แม้คำตอบผิด อาจได้คะแนนขั้นตอน
4. **ข้อยาวแบบ 2-3 ขั้น (ผสมนำ+พา+รังสี)** แยกคำนวณเป็นส่วนๆ แล้วค่อยบวก
5. **เหลือเวลา 5 นาทีสุดท้าย** ไล่เช็กหน่วยกับกับดักในส่วนที่ 4

## ความร้อนของปฏิกิริยา

**21.** ในการศึกษาเกี่ยวกับความร้อนที่เปลี่ยนแปลงในปฏิกิริยา อุปกรณ์ใดไม่จำเป็นต้องใช้ในการทดลอง

- ก. กระจกนาฬิกา
- ข. กล่องโฟม
- ค. ภาชนะพลาสติก
- ง. แท่งกวน
- จ. เทอร์โมมิเตอร์

**22.** ข้อใดไม่ใช่จุดประสงค์หลักในการศึกษาความร้อนของปฏิกิริยาเคมี

- ก. เพื่อหาค่าความร้อนของปฏิกิริยาสะเทินระหว่างกรดแก่และเบสแก่
- ข. เพื่อศึกษาพฤติกรรมการถ่ายโอนความร้อนในขณะที่มีปฏิกิริยาเคมีเกิดขึ้นในระบบ
- ค. เพื่อหาค่าความจุความร้อนของแคลอริมิเตอร์
- ง. ข้อ ก. และ ข. เป็นจุดประสงค์หลัก
- จ. ทั้ง ข้อ ก., ข. และ ค. เป็นจุดประสงค์หลัก

**23.** ข้อใดกล่าวผิด

- ก. ระบบที่เกิดปฏิกิริยาแบบคายความร้อนจะมีผลให้สิ่งแวดล้อมมีอุณหภูมิสูงขึ้นอย่างแน่นอน
- ข. ในแง่ของความร้อน ปฏิกิริยาเคมี[ข้อความบางส่วนถูกภาพบัง]กิริยาแบบคายความร้อน และ ปฏิกิริยาแบบดูดความร้อน
- ค. แคลอริเมตรีเป็นการศึกษาเกี่ยวกับการเปลี่ยนแปลงความร้อนในปฏิกิริยาเคมีของกรดและเบสเท่านั้น
- ง. ระบบที่เกิดปฏิกิริยาแบบดูดความร้อนน่าจะมีผลให้สิ่งแวดล้อมมีอุณหภูมิต่ำลง
- จ. ไม่มีข้อใดกล่าวผิด

**24.** ในการศึกษาเกี่ยวกับการเปลี่ยนแปลงความร้อนของปฏิกิริยาเคมีนั้น พบว่าการเปลี่ยนแปลงอุณหภูมิของปฏิกิริยามักเกิดขึ้นอย่างรวดเร็วจนเทอร์โมมิเตอร์วัดได้ไม่ทัน จงบอกวิธีการหาอุณหภูมิผสมหลังการเกิดปฏิกิริยา

- ก. นำค่าแต่ละค่าของอุณหภูมิผสมหลังการเกิดปฏิกิริยามาบวกกันแล้วหารด้วยจำนวนข้อมูลในการทดลองจะได้เป็นค่าเฉลี่ย
- ข. สามารถใช้อุณหภูมิเฉลี่ยของน้ำร้อนและน้ำเย็นในการคำนวณได้เนื่องจากค่าไม่แตกต่างกันมาก
- ค. นำอุณหภูมิผสมหลังการเกิดปฏิกิริยาแต่ละค่าและเวลามาพล็อตกราฟแล้วลากเส้นตรงผ่านจุดที่ได้ให้มากจุดที่สุดไปตัดแกน Y ถือว่าอุณหภูมิที่จุดนั้นเป็นอุณหภูมิผสมหลังเกิดปฏิกิริยา
- ง. ทุกข้อที่กล่าวมามีความเป็นไปได้ในทางปฏิบัติ
- จ. ข้อ ก น่าจะมีความเป็นไปได้มากที่สุดในทางปฏิบัติหากมีจำนวนข้อมูลมากเกินพอ

**25.** ค่าความร้อนของปฏิกิริยาเคมีระหว่างกรดและเบสสามารถนำไปหาความเข้มข้นของกรดตัวอย่างได้หรือไม่

- ก. ได้ เพราะค่าความร้อนของปฏิกิริยาเคมีสัมพันธ์กับความเข้มข้นของกรด
- ข. ไม่ได้ เพราะค่าความร้อนของปฏิกิริยาเคมีไม่สัมพันธ์กับความเข้มข้นของกรด
- ค. ได้ แต่ต้องทราบพลังงานภายในของระบบนั้น ๆ
- ง. ไม่ได้เพราะการศึกษาหาค่าความร้อนของปฏิกิริยาเคมีระหว่างกรดและเบสต้องกระทำที่ความเข้มข้น 1 M เท่านั้น
- จ. ได้ หรือ ไม่ได้ขึ้นอยู่กับปริมาณกรดและเบสที่ใช้ในการทดลอง

**26.** จากคำจำกัดความของปฏิกิริยาสะเทิน "ปฏิกิริยาสะเทิน เป็นปฏิกิริยาระหว่างกรดกับเบสได้ผลิตภัณฑ์เป็นน้ำ ปฏิกิริยาเกิดขึ้นเร็วมาก และเป็นปฏิกิริยาคายความร้อน" ต่อไปนี้ข้อใดผิด

- ก. HCl + NaOH → H₂O + NaCl  ΔH มีค่าเป็นบวก
- ข. HCl + NaOH → H₂O + NaCl  ΔH มีค่าเป็นลบ
- ค. H⁺ + OH⁻ → H₂O
- ง. เมื่อปฏิกิริยาสิ้นสุด และถ้าจับภาชนะบรรจุจะรู้สึกว่าร้อนขึ้น
- จ. การวัดค่าอุณหภูมิของปฏิกิริยาสะเทินต้องเริ่มทันทีที่การเทกรดผสมกับด่างสิ้นสุดลง

**27.** การทดลองปฏิกิริยาสะเทิน HCl ด้วย NaOH ใช้ HCl 24.00 ml น้ำกลั่น 1.00 ml และ NaOH 25.00 ml สารใดเป็นสารกำหนดปริมาณ

## เทคนิคการไทเทรต

- จ. วิเคราะห์โดยสีของสารที่เปลี่ยนไป

**42.** ข้อใดเป็นเทคนิคการไทเทรตที่ถูกต้อง

- ก. บิวเรตที่ใช้ต้องสะอาด โดยก่อนเติมสารลงในบิวเรตต้องกลั้วด้วยน้ำกลั่นแล้วเติมสารที่ต้องการลงในบิวเรตให้ได้ปริมาตรที่ต้องการ
- ข. การอ่านขีดบอกระดับ สายตาต้องอยู่ในแนวสูงกว่าระดับของเหลวในบิวเรตประมาณ 2.5 ซ.ม.
- ค. การดูดสารละลายหรือน้ำกลั่นเข้าสู่ปิเปต สามารถใช้ปากดูดได้ เพื่อความสะดวก
- ง. เมื่อปล่อยสารละลายจากปิเปตสู่ภาชนะรองรับ ห้ามเป่าไล่สารละลายออกจากปิเปตเด็ดขาด
- จ. เทคนิคที่กล่าวมาถูกทุกข้อ

**43.** ข้อใดเป็นการกระทำที่ผิด

- ก. กลั้วบิวเรตด้วยสารละลายที่จะบรรจุลงในบิวเรต
- ข. ปริมาตรของสารในบิวเรตไม่เริ่มต้นที่ 0.00 mL
- ค. กลั้วปิเปตด้วยสารละลายที่จะปิเปตมาใช้
- ง. ใส่สารอินดิเคเตอร์ลงในบิวเรต
- จ. ฉีดน้ำกลั่นชะข้างขวดรูปชมพู่ในระหว่างไทเทรต

**44.** สารละลายมาตรฐานในการทดลองที่นักศึกษาใช้คือ

- ง. pH ที่จุดสมมูล = 7 , pH ที่จุดยุติ = 5
- จ. ไม่มีข้อใดถูก

**46.** การไทเทรตกรดแก่กับเบสแก่ ใช้สารอะไรเป็นอินดิเคเตอร์ ให้สีของสารละลายเปลี่ยนแปลงอย่างไร

- ข. แอมโมเนีย-แอมโมเนียมคลอไรด์ สีม่วงแดง → สีชมพู

- ง. การจุ่มโลหะ Pb ลงในสารละลาย Sn²⁺
- จ. การจุ่มโลหะ Zn ลงในสารละลาย Cu²⁺

**62.** ข้อใดกล่าวถูกต้องเมื่อต่อ ครึ่งเซลล์ Pb(s)/Pb²⁺(1M) กับ ครึ่งเซลล์ Zn(s)/Zn²⁺(0.01M)

- ก. ปฏิกิริยาออกซิเดชันคือ Pb → Pb²⁺ + 2e⁻
- ข. ปฏิกิริยาที่ขั้วบวกคือ Zn → Zn²⁺ + 2e⁻
- ค. จะมีการผุกร่อนของโลหะสังกะสี
- ง. วัดแรงเคลื่อนไฟฟ้าได้เท่ากับ 0.634 โวลต์
- จ. ตัวออกซิไดส์คือ Pb

**63.** โลหะชนิดใดบ้างที่ไม่ผุกร่อน เมื่อจุ่มในสารละลายกรด

- ก. Pb
- ข. Sn
- ค. Zn
- ง. Cu
- จ. ถูกทุกข้อ

**64.** ข้อใดกล่าวไม่ถูกต้องเกี่ยวกับเซลล์ความเข้มข้น

- ก. ประกอบด้วยครึ่งเซลล์ชนิดเดียวกัน 2 ครึ่งเซลล์
- ข. มีแรงเคลื่อนไฟฟ้ามาตรฐานเท่ากับ 0
- ค. มีการถ่ายเทอิเล็กตรอนจากสารละลายที่มีความเข้มข้นต่ำไปยังสารละลายที่มีความเข้มข้นสูง
- ง. แรงเคลื่อนไฟฟ้าจะน้อยเมื่อสารละลายทั้ง 2 ครึ่งเซลล์ มีความเข้มข้นต่างกันมาก
- จ. แรงเคลื่อนไฟฟ้าของเซลล์ความเข้มข้นสามารถคำนวณได้จากสมการเนินสท์

**65.** จากแผนภาพแบบย่อของ กัลวานิกเซลล์ M / M²⁺ // N²⁺ / N ข้อใดผิด

- ก. ด้านซ้ายของ // คือ ขั้วลบของเซล
- ข. ด้านซ้ายของ // คือ ขั้วบวกของเซล
- ค. ด้านซ้ายมือ เกิดปฏิกิริยาออกซิเดชัน
- ง. ด้านซ้ายมือขั้ว Electrode ให้อิเลคตรอน
- จ. ด้านซ้ายมือต่อกับขั้วลบของกัลวาโนมิเตอร์

**66.** เวลาจุ่มแท่งโลหะลงในสารประกอบ CuSO₄ แล้วเกิดสีดำเกาะที่ขั้วโลหะ ข้อใดผิด

- ก. เกิดปฏิกิริยาเคมีขึ้น
- ข. Cu²⁺ รับอิเลคตรอนจากแท่งโลหะ
- ค. Cu²⁺ ให้อิเลคตรอนกับแท่งโลหะ
- ง. เกิดปฏิกิริยารีดอกซระหว่างแท่งโลหะและสารละลาย
- จ. แท่งโลหะทำหน้าที่เป็นตัว reducer

**67.** จากสมการ E = E° − (0.0592/n) log ([ผลิตภัณฑ์]/[สารตั้งต้น]) ข้อใดผิด

- ก. E° = E°(Cathode) − E°(Anode)
- ข. E° = E°(Oxidation) + E°(Reduction)
- ค. n = 2
- ง. [ผลิตภัณฑ์] คือค่าความเข้มข้นของขั้วลบ
- จ. [ผลิตภัณฑ์] คือค่าความเข้มข้นของขั้วบวก

**68.** ข้อความต่อไปนี้ข้อใดผิด

- ก. ค่า E°cell คือค่าศักย์ไฟฟ้าของเซลที่ค่าความเข้มข้นของสารอิเลคโตรไลท์ เท่ากับ 1M วัดที่ 25 °C
- ข. ในเซลความเข้มข้นใช้สารอิเลคโตรไลท์ชนิดเดียวกันแต่มีค่าความเข้มข้นต่างกัน
- ค. ในเซลความเข้มข้นใช้สารอิเลคโตรไลท์ต่างชนิดกันแต่ค่าเข้มข้นเดียวกัน
- ง. ค่า E°cell ของเซลความเข้มข้นมีค่าเป็นศูนย์
- จ. ข้อ ก, ข, ง ถูก

**69.** เครื่องมือที่ใช้วัดแรงเคลื่อนไฟฟ้าในการทดลองเรื่องไฟฟ้าเคมีเรียกว่า

- ก. วัตต์มิเตอร์
- ข. pH มิเตอร์
- ค. มาโนมิเตอร์
- ง. โวลต์มิเตอร์
- จ. แอมมิเตอร์

**70.** สะพานเกลือทำหน้าที่

- ก. เป็นทางเดินของอิเล็กตรอน
- ข. เชื่อมวงจรเข้าด้วยกัน
- ค. ดุลประจุของไอออนในเซลล์ไฟฟ้า
- ง. เป็นสะพานไฟฟ้า
- จ. เชื่อม 2 ครึ่งเซลล์เข้าด้วยกัน

## การวิเคราะห์เชิงคุณภาพ

**71.** ในการวิเคราะห์เชิงคุณภาพของไอออน ข้อใดต่อไปนี้ไม่ใช่สิ่งที่สังเกต

- ก. สีของสารละลาย
- ข. การตกตะกอน
- ค. ฟองก๊าซ
- ง. การเปลี่ยนแปลงความร้อน
- จ. ค่า pH

**72.** Blank Test ใช้สารใดในการทดสอบ

- ก. น้ำประปา
- ข. น้ำกลั่น
- ค. สารมาตรฐาน
- ง. สารตัวอย่าง
- จ. ไม่มีข้อใดถูก

**73.** Control Test คืออะไร

- ก. ทดสอบโดยไม่เติม reagent
- ข. ทดสอบโดยไม่ใส่สารตัวอย่าง
- ค. ทดสอบโดยใช้น้ำกลั่นแทนสารตัวอย่าง
- ง. ทดสอบโดยใช้สารละลายไอออนแทนสารตัวอย่าง
- จ. ไม่มีข้อใดถูกต้อง

**74.** ข้อใดไม่ถูกต้องเกี่ยวกับการสังเกตตะกอน

- ก. ถ้าสารละลายขุ่นแสดงว่ามีตะกอน
- ข. บางครั้งตะกอนที่เกิดขึ้นมีลักษณะเป็นคอลลอยด์
- ค. ตะกอนไม่จำเป็นต้องมีสีเดียวกับสารละลาย
- ง. ตะกอนที่มีสีและลักษณะเหมือนกันแสดงว่าเป็นสารชนิดเดียวกัน
- จ. ตะกอนสามารถแยกออกจากสารละลายด้วยเครื่องหมุนเหวี่ยง

**75.** การทดสอบไอออนใดที่ให้ผลเป็นบวกโดยการสังเกตว่ามีตะกอนเกิดขึ้น

- ก. Cl⁻
- ข. CH₃COO⁻
- ค. SCN⁻
- ง. NH₄⁺
- จ. CO₃²⁻

**76.** ในการทดสอบไธโอไซยาเนตไอออนจะสังเกตเห็นอะไร

- ก. สารละลายสีฟ้าชั่วครู่
- ข. ตะกอนสีขาว
- ค. สารประกอบเชิงซ้อนสีแดงเข้ม
- ง. มีฟองแก๊สเกิดขึ้น
- จ. กลิ่นของน้ำส้มสายชู

**77.** การทดสอบไอออนตัวใดที่ใช้กระดาษลิตมัสช่วยในการวิเคราะห์ผล

## ⚡ ทริกทำข้อสอบให้เร็วและแม่น

### ทริกทั่วไป
1. **อ่านคำถามให้ครบก่อนเลือก** ดูให้ดีว่ามีคำว่า **NOT** หรือเปล่า ถ้าเจอโจทย์แบบ NOT ให้เช็กทีละตัวเลือกว่า "ถูกหรือผิด" ตัวไหนผิดตัวเดียวคือคำตอบ
2. **ตัดตัวเลือกที่ผิดแกรมม่าร์ออกก่อน** (เช่น should to / will goes / don't should) ส่วนใหญ่จะเหลือแค่ 1–2 ตัว
3. **คำที่สะกดคล้ายกัน** เช่น politician / politicist / politics ให้ตัดคำที่ "ไม่มีจริง" ออกก่อน
4. **ข้อไหนคิดเกิน 1 นาที ให้ข้ามไปก่อน** วงไว้แล้วค่อยกลับมาทำ (90 ข้อ / 120 นาที ≈ ข้อละ 1 นาทีกว่า)
5. **ฝนคำตอบให้ตรงข้อ** เช็กทุก 10 ข้อว่าเลขข้อตรงกัน

### ทริก Vocabulary
- **ดูคำนามหลังช่องว่างก่อน** แล้วจับคู่กับกริยา (collocation)
- **หาคำใบ้ในประโยค** เช่น "between hills" + "low" → valley / "edge" + "100 meters high" → cliff
- **โจทย์ถามนิยาม** ให้แปลนิยามเป็นไทยในใจ แล้วจับคู่

### ทริก Grammar (สำคัญที่สุด)
- **ประธานเป็น he / she / it** (ชื่อคน 1 คน, my brother, my mom) → does / doesn't / has to / กริยาเติม s
- **หลัง did / does / do / will / should / can / might / may** → กริยาช่อง 1 เปล่า ๆ เสมอ (ไม่เติม s ไม่เติม ed)
- **ถามตัวเองว่า "มีกริยาตัวอื่นไหม?"**
  - มี → do / does / did
  - ไม่มี (ตามด้วยคำคุณศัพท์ / สถานที่ / คำนาม) → am / is / are / was / were
  - ตามด้วย V-ing → am / is / are / was / were
- **ห้ามใช้ don't / doesn't กับ should, will, can, going**
  - shouldn't ✅ / won't ✅ / can't ✅ / aren't going ✅

### ทริก Reading
1. **อ่านคำถามก่อน** แล้วค่อยกลับไปหาคำตอบในบทอ่าน
2. **ข้อที่มีตัวเลขต้องเช็กทุกครั้ง** ข้อสอบชอบเปลี่ยนตัวเลขนิดเดียว (50 → 500)
3. **ระวังคำแรง ๆ** always / never / only / all ตัวเลือกที่มีคำพวกนี้มักผิด
4. **ประโยคแรกของแต่ละย่อหน้า** มักบอกใจความหลัก
5. **คำแทน** it / they / this / that ให้ย้อนดูว่าหมายถึงอะไรในประโยคก่อนหน้า
6. **ศัพท์ไม่รู้ความหมาย** ดูชนิดคำ + คำรอบ ๆ แล้วเดา

## 🚨 จุดที่ตัวเองเคยพลาด (อ่านเช้าวันสอบ!)

1. **look forward to + V-ing** → looking forward to **seeing** you (ไม่ใช่ ~~see~~)
2. **he / she / it** → **Does** your brother...? / My brother **has to**... / She hardly ever answer**s**
3. **did กับ was / were** → They **didn't have** (มีกริยา have) / Where **were** you? (ไม่มีกริยา)
4. **หลัง did ต้องเป็นช่อง 1** → Did he **study**? (ไม่ใช่ ~~studied~~) / Did you **go**? (ไม่ใช่ ~~went~~)
5. **going to ต้องครบ 3 ส่วน** → I **am going to** study (ขาด am ❌ ขาด to ❌)
6. **ปฏิเสธ going** → We **aren't** going (ไม่ใช่ ~~don't going~~)
7. **ปฏิเสธ should** → **shouldn't** (ไม่ใช่ ~~don't should~~)
8. **will กับ won't ก็ "มั่นใจ" ทั้งคู่** → ที่ไม่แน่ใจคือ may / might
9. **in / on / at** → **in** the summer / **on** Sunday / **at** 5:00 / **last** night (ไม่มีบุพบท)
10. **have an argument** ✅ (have ใช้ได้กับ fun, an argument, a problem)

## 8. -ed / -ing adjectives (p.41)

- **-ed** = **คน**รู้สึก → I'm **bored**.
- **-ing** = **สิ่งของ / เหตุการณ์** ที่ทำให้รู้สึก → The movie is **boring**.
- คำ: amazing/ed, boring/ed, confusing/ed, exciting/ed, relaxing/ed, disappointing/ed, embarrassing/ed, interesting/ed, shocking/ed, tiring/tired

**ทริก 3 วินาที: ดูคำหน้าช่องว่าง**
- **คน** + is / was / feel → **-ed**
- **สิ่งของ / เหตุการณ์** + is / was → **-ing**
- **It** is / was → **-ing**
- a / an / the + ___ + **คำนาม** → **-ing** (an amazing show)
- **feel** + -ed เสมอ
- interested **in**

## 9. have / take / do / make (p.46)

| กริยา | + คำนาม |
|---|---|
| **MAKE** | a mistake, a decision, an effort, an excuse, money |
| **TAKE** | a break, a chance, a class, an exam, a nap, my/your time, advantage **of** |
| **DO** | homework, someone a favor, something wrong |
| **HAVE** | fun, an argument, a problem |

**ทริก: ไล่เช็กตามลำดับ**
1. อยู่ใน **Make 5 อย่าง** (Mistake, Decision, Effort, Excuse, Money) ไหม → **make**
2. อยู่ใน **do 3 คำ** (homework, a favor, something wrong) หรือ **have 3 คำ** (fun, an argument, a problem) ไหม
3. ไม่อยู่ในกลุ่มไหนเลย → **take**

- รูปกริยา: make-made-made / take-took-taken / do-did-done / have-had-had
- ❌ do a mistake / make homework / make a favor / do a decision / take advantage the club

# 📐 PART 2: GRAMMAR (30 ข้อ)

## 1. Simple present + frequency adverbs (p.7, 132)

| | I / You / We / They | He / She / It |
|---|---|---|
| + | I **work** | She **works** |
| − | I **don't work** | She **doesn't work** |
| ? | **Do** you work? | **Does** she work? |

- เติม -es: watch**es**, go**es** / พยัญชนะ+y → tr**ies** / have → **has**
- **Adverbs (100% → 0%):** always > almost always > usually > often > sometimes > occasionally > hardly ever > never
- **ตำแหน่ง:** หน้ากริยาแท้ (She **usually** has...) / หลัง be (I'm **sometimes** late)
- once a week / every day → ต้นหรือท้ายประโยค
- ถามความถี่: **How often** do you...?
- ❌ doesn't likes / Does she goes / I go always / I always am / don't never

## 2. Simple past (p.16, 133)

| | กริยาทั่วไป | verb to be |
|---|---|---|
| + | He **walked** / He **went** | I/he/she/it **was** · you/we/they **were** |
| − | He **didn't go** | **wasn't / weren't** |
| ? | **Did** he **go**? | **Was** he...? / **Were** you...? |

- เติม -ed: decide**d** / tr**ied** / stay**ed** / sto**pped**
- อปกติ: broke, lost, swam, thought, slept, drank, woke, found, could, went, had, saw, got, made, took
- **ทริก: มีกริยาตัวอื่นไหม? มี → did / ไม่มี → was / were**
- ❌ Did she had / didn't stayed / he were / spended / breaked / tryed / Did you was?

## 3. Question review (p.27, 134)

- **Wh- question: ค-ช-ป-ก** = **ค**ำถาม + กริยา**ช**่วย + **ป**ระธาน + **ก**ริยาหลัก
  - Where **do** your parents **live**? / What **was** he **doing**?
- **Yes / No:** กริยาช่วย + ประธาน + กริยาหลัก → **Did** she **take** a photo?
- **verb to be ไม่ใช้ do** → **Is** she an icon? (❌ Does she be) / How old **was she**? (❌ she was)
- **บุพบทไว้ท้าย** → What is he famous **for**? / Who was she talking **to**?

**เลือกคำถามจากคำตอบ:** What (สิ่งของ) / Where (สถานที่) / When (เวลา) / Who (คน) / Why (เหตุผล) / How long (ระยะเวลา) / How old (อายุ) / How often (ความถี่) / How tall (ความสูง)

**เลือกกริยาช่วยจากคำหลังประธาน:**
- V-ing / ไม่มีกริยา → am / is / are / was / were
- กริยาช่อง 1 → do / does / did
- มี can / will / should → ใช้ตัวนั้น

## 4. going to & present continuous for plans (p.37, 135)

| | รูป | ใช้เมื่อ |
|---|---|---|
| **going to** | am / is / are + going to + **V1** | ความตั้งใจ (intention) |
| **present continuous** | am / is / are + **V-ing** | แผนที่นัดแน่นอน มีเวลา / สถานที่ |

- I'**m going to study** law. / I'**m meeting** Juan tonight at 7.
- go → ละ "to go" ได้: Jack's **going swimming**
- ❌ I going to (ขาด am) / I am going study (ขาด to) / going to studying / I meet Juan tonight / We don't going / Tom doesn't going

## 5. should / have to / can't for advice (p.47, 136)

| ระดับ | รูป |
|---|---|
| 💪 Strong | **have to / has to** + V1 / **can't** + V1 |
| 👉 Direct | **should / shouldn't** + V1 |
| 🙂 Indirect | **I think** you should... / **I don't think** you should... |

- ถาม: What **should** I do?
- ❌ should to / shoulds / should goes / don't should / He have to
- **can't** = ห้าม / **don't have to** = ไม่จำเป็น
- Marina: Harry → join a club / Tanya → have to take breaks + I don't think you should quit / Esther → help your community

## 6. will / may / might for predictions (p.49, 136)

- **will / won't** = มั่นใจ / **may / might (not)** = ไม่แน่ใจ (may = might ใช้แทนกันได้)
- **คำถามใช้ will เท่านั้น** → **Will** robots be the solution?
- **definitely / probably: หลัง will แต่หน้า won't**
  - She'll **probably** come. / She **probably** won't come.
- **100% → 0%:** will definitely > will > will probably > may/might > may not/might not > probably won't > won't > definitely won't
- ❌ will to go / will goes / won't probably / don't will / willn't / mayn't

# 💬 PART 3: FUNCTIONAL LANGUAGE (15 ข้อ)

## 1. Checking understanding (p.13)
- **เช็กข้อมูล:** Is that right? / Do you mean...? / Did you say...?
- **ไม่เข้าใจ:** Could you say that again, please? / What do you mean? / I'm sorry, but I don't understand.
- **ยืนยันว่าเขาเข้าใจถูก:** That's right. / You've got it. / Exactly!
- **บอกว่าเราเข้าใจแล้ว:** (Now) I understand. / (I've) got it. / I see (what you mean).

## 2. Telling a story & reacting (p.23)
- **เล่า:** That reminds me of... / Did I ever tell you about...? / It was... / One day,... / Anyway,... / ...when suddenly... / **In the end,...** (จบเรื่อง)
- **ประหลาดใจ:** Really? / No way!
- **สนใจ:** Keep going. / Then what happened?
- **ข่าวร้าย:** Oh, no. / That's awful!
- **ข่าวดี:** That's great! / Lucky you!

## 3. Agreeing & disagreeing (p.33)
- ✅ **เห็นด้วย:** I totally agree. / I agree with that. / Absolutely! / I suppose so. (อ่อน)
- ❌ **ไม่เห็นด้วย:** I'm not sure I agree with that. (อ่อน) / I'm afraid I disagree. / I don't think so. / I completely disagree. / No way! (แรง)
- 🤔 **เห็นด้วยบางส่วน (มี but):** I see your point, but... / I know what you mean, but... / True, but, actually,...

## 4. Making plans (p.43)
- What are you doing / up to...? → Nothing special. / Not much.
- Do you feel like **+ V-ing**? → That sounds great! / I'd love to.
- What / How about **+ V-ing**? → I'm afraid I can't. / Sorry, I'm busy.
- When can you make it? → I'm free on... / I can make it on...
- What time is good? → ...is tricky. / I can't make it...

## 5. Asking for & giving advice (p.53)
- **ขอ:** What would you do? / What do you think I should do? / Do you think I should...? / What do you suggest? / Can you give me some advice? / What would you recommend?
- **ให้:** Why don't you + V1? / **If I were you**, I would + V1 / I (don't) think you should... / It's (not) a good idea to... / How about + V-ing? / You should / **ought to** + V1
- ⚠️ If I **were** you (ไม่ใช่ was)

## 6. Giving thanks (p.63)
- **ขอบคุณทั่วไป:** Thanks. / Thank you. / Thanks a lot.
- **ขอบคุณที่ช่วย:** Thanks for... / Thank you so much. / I really appreciate it.
- **ขอบคุณสำหรับของขวัญ:** That's very kind of you. / You didn't need to do that.
- **ทางการ:** I'm very grateful. / I don't know what to say.
- **ตอบรับคำขอบคุณ:** No problem. / You're welcome. / My pleasure. / Don't mention it. / It's nothing, really. / It's the least I can do.
- ⚠️ A ขอบคุณ → B ต้อง**ตอบรับ** (ไม่ใช่ขอบคุณกลับด้วย I really appreciate it)
- ⚠️ ได้ของขวัญ → ต้อง**ขอบคุณ** (ไม่ใช่ You're welcome)
